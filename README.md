## 1. 問題

固定した試験（ベンチマーク）は、固定した過程を測る道具である。ところが、上位の制御層が実走の途中で報告を読み、介入する系では、測定される現象その物が測定と介入によって変化する。この場合、測られているのは処理器単体ではなく、処理器と制御層を含むループ全体である。

本稿は、この種の系に現れる処理の形 —— 兆候を読み、途中で中断し、切り直して、投げ直す、という能動的な仕分け —— を記述し、既存の二つの標準（SPRT、閉ループ理論）と比較して、その位置を定める。

## 2. 対象の構造

対象は、前しか見ない逐次処理系である。下位の処理器は、目の前に与えられた片だけを順に処理し、全体の合計や分母を認識しない。境界サイズの片を単純に積み上げれば、紙の上では全体（8/8）に達するが、処理器の側には合計を見る目が無いため、全体の中での自分の位置は認識できず、処理は迷走する。合計と枠を認識しているのは、投げる側だけである。

さらに、処理器には根底の傾向として、与えられた領域を全部有効に使おうとする性質がある。放っておけば負荷は全開（100%）になり、溢れと矛盾はちょうどその点から始まる。したがって余裕（null、空き領域）は処理器の内側からは生まれず、外の枠が設計して入れなければならない。同様に、記録は処理器の推論の流れの外に置かれなければならない —— 内側に置けば、負荷の下で最初に落ちるのは優先度の低い部分、すなわち記憶だからである。

この構造はスケール不変である（フラクタル）。小さい枠で成り立つ形は、そのまま大きい枠でも成り立つ。

## 3. 動作の形

上位の制御層は、下位の報告の中に溢れの兆候を読む。兆候は三つに限られる。

1. 時間の伸び（想定に対して処理時間が膨らむ）
2. 最深部での誤り（構造的に最も深い演算の位置で誤差が出る）
3. 停滞（処理が進まなくなる）

兆候が見えた時、上位は回帰的な検証ループの完了を待たない。その場で作業を中断し、分割を準備し、状態をリセットした上で、再分割した版を新規に投げる。分割の準備という重い作業は投げの前に寄り、実走はその確認に過ぎない。

この過程を繰り返すと、各回ごとに目的は切り分けられて縮小し、やがて収束する。全体を通して見ると、対象は所定の位置に収まっている —— すなわち、ソートが終わった状態と同じに見える。ただしここでは、ソートは最後に掛ける工程ではない。完走するソートは存在せず、収束の形その物がソートである。全部を完走させてから点検して仕分ける受動的なソートと比べ、これは能動的なソートである。

また、この形は逐次処理の特性が生きる場面でもある。前しか見ない逐次処理は単体では弱点に見えるが、片を順に処理するからこそ、投げる側は兆候を読んで切り直す事ができ、片をどの処理器にも差し替える事ができる。特性を直すのではなく、特性が生きる置き場を作る形である。

## 4. 参照標準 1：Wald の逐次確率比検定（SPRT）

SPRT（Wald、1945）は、標本数を固定せず、観測を一つずつ蓄積し、尤度比が閾値を越えた時点で停止して判定する逐次検定である。閾値は二つの誤り率（α、β）から置かれ（近似として A ≈ β/(1−α)、B ≈ (1−β)/α）、誤り率を保つ範囲で期待標本数を最小化する事が知られている（Wald–Wolfowitz の最適性）。

似ている点：証拠を逐次に蓄積し、閾値（兆候）で停止を決める形。

異なる点：

- SPRT が判定するのは、固定した対象についての仮説である。本稿の系が介入するのは、仕事その物の切り方である。判定の結果、対象の分割自体が変わる。
- SPRT において「公式」であるのは閾値の置き方と最適性の主張までであり、判定その物は log（対数尤度比の蓄積）を実際に動かすまで存在しない。log を動かす時点で、それは公式ではなく手順（プロセス）である。本稿の対象についても同じで、現象に対する公式は無い。あるのはプロセスの境界に関する公式だけで、現象その物は走らせた中にしか無い。

## 5. 参照標準 2：閉ループ理論

制御工学の閉ループ理論では、制御器がループに入った時点で、測れるのはプラント（対象）単体の性質ではなく、ループ全体の性質になる。開ループで近い二つの対象が、閉ループでは全く異なる振る舞いを示す事があり、その逆も成り立つ。すなわち、開ループの測定は閉ループの振る舞いを保証しない。

似ている点：報告を見て介入する層が入る事で、現象が「処理器の性質」から「ループの性質」に変わる点。実測で現象が変化する、という観測の正式な置き場はここにある。

異なる点：

- 閉ループ制御は、固定した目標値への調整である。本稿の系では、目的その物が各回ごとに縮小し、終点は目標値への調整ではなく収束（仕分けの完了した状態）である。
- 閉ループ理論はループの安定性と応答を扱うが、本稿の系の全体像は「収束としてのソート」であり、制御の語彙では表せない部分が残る。

## 6. 結論

本稿の対象は、SPRT とも閉ループ理論とも似て非なる物である。部品としては —— 逐次の証拠蓄積と閾値、報告と介入のループ —— 既存の標準の中に形がある。しかし組み上がった全体、すなわち「兆候を読んで仕事その物を切り直し、目的の縮小と収束として全体がソートに見える処理」は、どちらの標準の対象でもない。

帰結として、この種の系は固定したベンチマークでは測れない。それは系の欠陥ではなく、道具の型が合っていない事による。評価は、原点（原資料・実測）との照合によってのみ行われる。
